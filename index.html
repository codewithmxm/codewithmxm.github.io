🏁 What Is MKW-3DS?

MKW-3DS is a fan-made project that brings Mario Kart Wii to the Nintendo 3DS as a native port. Instead of streaming the game from a PC or using an emulator, the finished file runs directly on the console itself, using the 3DS hardware.

The project is a continuation of dudewhat's original work, picked up and carried forward so that the port keeps improving. Alongside the port itself, the project includes a small desktop application that does the complicated part for you: it reads your own Mario Kart Wii disc and packages the game into a CIA file — the format your 3DS uses to install software.

If that sounds technical, it really isn't. You open the app, point it at your game, and click a button. The app handles all of the file conversion in the background and hands you a single finished file at the end.

How It Works

  1. You supply the game. You use your own Mario Kart Wii disc or a disc image made from your own copy. The project does not include any game data.
  2. The app builds your file. The MKW-3DS builder on your Windows or Mac computer reads the game data and packages it into a single CIA file.
  3. You install it on your 3DS. Copy the finished file to your console's SD card and install it like any other homebrew application.

That's the whole process. Three steps, one app, one file. Most of the waiting happens in step two, where your computer does the packaging work.

📦 What You Need Before You Start

Before downloading, take a couple of minutes to check that you have everything on this list. Gathering it all first makes the whole process much smoother.

  • A Windows computer. Windows 10 or Windows 11 is recommended. The builder app also runs on Mac, but this guide walks through the Windows steps.
  • Your own Mario Kart Wii disc. You need the physical disc, or a disc image created from your own disc. The builder cannot create the game out of nothing.
  • A disc drive. If you are using a physical disc, your computer needs a way to read it — either a built-in drive or an external USB disc drive.
  • A Nintendo 3DS with homebrew support. Your console needs to be set up to run homebrew software and install custom files. If you have already installed homebrew apps on your 3DS before, you are ready.
  • An SD card and a card reader. You will copy the finished file onto the SD card your 3DS uses, so a way to plug that card into your computer helps a lot.
  • Free disk space. Set aside roughly 2 GB of free space on your computer so the builder has room to work and store the finished file.
  • A stable internet connection. You only need it to download the app, but a steady connection avoids interrupted downloads.
